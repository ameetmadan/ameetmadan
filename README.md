## How I work

- **Make illegal states unrepresentable.** Strict TypeScript, parse at the boundary, trust the types inside.
- **Decisions leave a trail.** I write ADRs and PR descriptions that still make sense in two years.
- **Privacy is architecture, not a policy page.** If it can run on the user's machine, it does.
- **Raise the floor for the team.** Component libraries, Storybook, CI, and shared standards, so the next feature is cheaper than the last.
